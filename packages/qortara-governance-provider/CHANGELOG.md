# Changelog

All notable changes to the Qortara Governance Provider proving-ground package are documented here.

## 0.1.0 - 2026-08-22

### Added

- Host-neutral ESM provider over Microsoft Agent Governance Toolkit `PolicyEngine`.
- Qortara Governance Exchange `0.1` output with preserved provider-native evidence.
- Fail-closed provider `unavailable`, `unsupported`, and `error` attribution without manufacturing AGT policy denials.
- Verified native allow, native deny, default-deny, non-terminal, malformed identity, and evidence-metadata tests.
- Independent Node 22 CI gate for the provider package.
